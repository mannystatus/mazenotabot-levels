## Updating the site

After adding levels or screenshots to `geometry_dash_levels.html`, run these commands from your Downloads folder to sync the changes to GitHub (which auto-rebuilds the live site):

```bash
git add geometry_dash_levels.html
git commit -m "add levels"
git push
```

To also include new screenshot images:

```bash
git add geometry_dash_levels.html screenshot1.png
git commit -m "add levels and screenshots"
git push
```

GitHub Pages rebuilds automatically after every push — changes are live within about a minute.
